# Practice 3 — Get Started with Hugging Face

Two **independent** exercises. Each folder has its own code, config, requirements, docs,
tests, outputs and report notebook; neither imports anything from the other.

| Folder | Task | Needs data? | Training? |
|---|---|---|---|
| [`exercise_1/`](exercise_1/README.md) | Pretrained sentiment inference + tokenization | No (just a sentence) | No |
| [`exercise_2/`](exercise_2/README.md) | Fine-tune DistilBERT on IMDb for binary classification | IMDb, downloaded automatically | Yes |

Windows: double-click `run_all.bat` (both exercises), `exercise_1\run_exercise_1.bat` or `exercise_2\run_exercise_2.bat`.
Otherwise work from inside the exercise folder (`cd exercise_1` or `cd exercise_2`) and follow its README.

Shared, course-level files kept at the top: `Practice_3_Requirements.md`, `progress.md`,
`AI_usage.md`, `AI_Usage_Step.md`, `docs/08_chapter4_alignment.md`, `docs/AI_Usage_Full.md`.
